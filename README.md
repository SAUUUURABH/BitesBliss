BITE BLISS

📋 Project Overview
Bite Bliss is a frontend-only food delivery web application designed to showcase a visually appealing and interactive interface. Built using HTML, CSS, and JavaScript, it allows users to browse menus and explore a simulated food delivery experience.

🚀 Features
Dynamic Content: Interactive menu cards and user-friendly interface.
Responsive Design: Optimized for desktops, tablets, and mobile devices.
CSS Animations: Enhanced user engagement with smooth animations.
JavaScript Interactivity: Click-based actions like adding items to the cart.
